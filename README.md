# privacy-lint

[![CI](https://github.com/ieee0824/privacy-lint/actions/workflows/ci.yml/badge.svg)](https://github.com/ieee0824/privacy-lint/actions/workflows/ci.yml)

Webサイトで個人情報を入力する前に、**入力する前に自分で確かめた方がよい点** を教えてくれるブラウザ拡張（Firefox / Chrome）。

たとえば「このサイトの運営会社はどこか」「入力した情報は何に使われるのか」「フォームの送信先はこのサイトなのか」。
普段は確かめずに入力してしまうこうした点を、ページから読み取れる事実をもとに洗い出して表示します。

サイトが安全か危険かは判定しません。確かめたうえで入力するかどうかを決めるのは利用者です。
観測できた事実と小さな意味判断（[TypeSafe Jev](https://docs.typesafe.ai)）をコードで合成し、根拠付きで表示します。

## 「追加で確認」とは

ポップアップに「入力前に確認をおすすめします」などと表示されたときに、**利用者が自分で確かめること** です。
表示される項目ごとに、確かめる内容は次のとおりです。

| 表示される項目 | 確かめること |
|---|---|
| ⚠ プライバシーポリシーへのリンクが見つかりませんでした | 「個人情報の取り扱い」などの別の名前で、個人情報の扱いの説明がサイト内に無いか。見つからなければ、入力をやめるか、入力前に問い合わせる |
| ⚠ 個人情報の利用目的を十分確認できませんでした | ポリシー本文やフォーム近くの説明を読み、入力した情報が何に使われるのか納得できるか |
| ⚠ 収集する個人情報の説明を確認できませんでした | どんな情報を集めるのかが、どこかに書かれているか |
| ⚠ プライバシーポリシーがこのフォームで求められる情報に触れているか確認できませんでした | 今入力しようとしている情報（例: 既往歴、生年月日）の扱いが、ポリシーに書かれているか |
| ⚠ フォームの送信先が現在のサイトとは異なるドメインです | 送信先のサービス（フォーム提供会社など）の名前がページで説明されているか。知っているサービスか |
| ⚠ 運営者情報のページが見つかりませんでした | 「会社概要」「特定商取引法に基づく表記」などのページがどこかに無いか。運営している会社・団体の名前と連絡先 |
| ⚠ サービスの運営主体を明確に確認できませんでした | 会社名・所在地・連絡先がどこかに書かれているか。その会社が実在するか |
| ⚠ ページ上の説明に対して、求められる個人情報が多い可能性があります | その項目は必須か、空欄のまま送れないか。なぜ必要なのか説明があるか |
| ⚠ フォームの送信先がHTTPSではありません | 入力しない。送信した内容が暗号化されずに送られるため |
| ⚠ このページはHTTPSで保護されていません | 入力しない。`https://` のページが別に用意されていないか |
| ℹ 第三者提供についての説明を確認できませんでした | 入力した情報が他の会社に渡されるかどうか、ポリシーに書かれているか |
| ℹ プライバシーポリシーの内容を取得できませんでした | リンク先を自分で開き、上の「利用目的」「第三者提供」などが書かれているか読む |
| ℹ 運営者への連絡手段を確認できませんでした | 住所・電話番号・メールアドレス・問い合わせフォームのいずれかがあるか |
| ℹ 求められる個人情報がやや多めです | 必須でない項目は空欄にできないか |
| ℹ フォームの送信先が同じサイト内の別のホストです | 通常は同じ運営者なので、特に確かめることはありません |
| ℹ 利用者向けの文書が長期間更新されていない兆候があります | 連絡先や説明が今も有効か（終了したサービス名や古い法令名が残っていないか） |
| ℹ 個人情報に関する問い合わせ窓口を確認できませんでした | 後から削除や訂正を頼みたくなったときの連絡先があるか |
| ℹ ○種類の外部サービスのスクリプトがこのページで動作しています | 情報としての表示だけで、特に確かめることはありません |
| ℹ ○○については判断に十分な情報が得られませんでした | 拡張が判断できなかった項目なので、上の表の該当する項目を自分で見る |
| 現在評価できません（ℹ 文書内容の評価サービスに接続できませんでした） | 評価サービスが使えない状態。HTTPS かどうか・ポリシーのリンクの有無など表示された項目に加え、上の各項目を自分で見る |
| ℹ 文書内容の評価（外部送信）は設定で無効になっています | ポリシーや運営者情報の中身は評価していないので、それらは自分で読む |

「特に注意を促す兆候は確認できませんでした」と表示された場合も、安全が確認されたという意味ではありません。
拡張が観測できた範囲で、確かめるべき点が見つからなかったという意味です。

## 何をどう判断するか

### いつ動くか

ページに **個人情報を入力する欄** が現れたときだけ動きます。
検索ボックスしかないページや、普通の記事ページでは何もしません（ツールバーのアイコンも無表示のまま）。

入力欄の種類は、`autocomplete` / `type` / `name` / `id` / `placeholder` / ラベルの文字から判定します（入力された値は読みません）。

| 種類 | 例 |
|---|---|
| 氏名 | `autocomplete="name"`、ラベル「お名前」、`name="namae"` |
| メール / 電話 / 住所 / 生年月日 | `type="email"`、ラベル「郵便番号」、表の隣のセル「電話番号」 |
| パスワード / 決済 / 本人確認 | `type="password"`、`autocomplete="cc-number"`、ラベル「マイナンバー」 |
| その他 | 勤務先、性別、既往歴 など |

### 何を見て、どう判断するか

| 観点 | 見るもの | 判断のしかた |
|---|---|---|
| 通信の保護 | ページとフォーム送信先が HTTPS か | コードで判定。HTTP なら最も強い注意 |
| フォームの送信先 | 送信先が同じサイトか、別ドメインか | コードで判定。別ドメインは「危険」ではなく確認材料として表示 |
| プライバシーポリシー | リンクがあるか。あれば本文から短い抜粋を取り出す | リンクの有無はコード、内容は Jev に 1 問ずつ質問（収集する情報 / 利用目的 / 第三者提供 / 問い合わせ窓口） |
| ポリシーとフォームの対応 | ポリシーが、このフォームで求める情報に触れているか | Jev |
| 運営者 | 会社概要・特定商取引法の表記・フッター | 運営主体を特定できるか、連絡手段があるかを Jev に質問 |
| 入力要求の妥当性 | ページの目的（タイトル・見出し・ボタン）と、求める情報の組み合わせ | Jev に 4 段階で評価させる（例: ニュースレターに生年月日は過剰の可能性） |
| 外部サービス | ページが読み込む第三者スクリプトの数 | コードで数えるだけ。多くても「危険」とはせず情報として表示 |

Jev の回答はそのまま使わず、確信度が低いものは「判断できなかった」として扱います。
最終的な段階はコードで合成します（詳細は [docs/scoring.md](docs/scoring.md)）。

### 結果の段階

| 段階 | ポップアップの見出し | ツールバー |
|---|---|---|
| 0 | 特に注意を促す兆候は確認できませんでした | （なし） |
| 1 | 念のため確認できる事項があります | `i` |
| 2 | 入力前に確認をおすすめします | `!` |
| 3 | 個人情報を入力する前に追加確認をおすすめします | `!!` |
| — | 判断に十分な情報が得られませんでした / 現在評価できません | `?` |

「安全です」とは表示しません。段階 2 以上のページで入力欄を操作し始めると、ページ右下に小さな通知も出ます（入力は妨げません）。

### 例

以下は `fixtures/` の評価用ページを実際に評価した表示です（Jev は mock）。

**ネットショップの購入画面**: ポリシー・特定商取引法の表記が揃っていて、求める情報も購入に見合っている

```text
特に注意を促す兆候は確認できませんでした

運営会社情報:         確認できました
プライバシーポリシー: 見つかりました
フォーム送信先:       このサイト
求められる情報:       住所、メールアドレス、氏名、決済情報、電話番号
```

**古いペンションの予約フォーム**: 住所・生年月日まで求めるのにポリシーが無く、送信先は外部のフォームサービス

```text
入力前に確認をおすすめします

⚠ フォームの送信先が現在のサイトとは異なるドメインです
⚠ プライバシーポリシーへのリンクが見つかりませんでした

運営会社情報:         確認できました
プライバシーポリシー: 見つかりませんでした
フォーム送信先:       別のドメイン
```

→ 確かめること: 予約した情報がどう扱われるかの説明がサイト内に無いか。送信先のフォームサービスがどこなのか。
説明が見つからなければ、電話で予約するなど別の方法も検討する。

**ニュースレターの購読フォーム**: 記事配信のためなのに住所・生年月日・勤務先まで求める

```text
入力前に確認をおすすめします

⚠ ページ上の説明に対して、求められる個人情報が多い可能性があります
```

→ 確かめること: 住所・生年月日・勤務先は必須か、空欄のまま購読できないか。なぜ必要なのか説明があるか。

**外部フォームサービスを使った資料請求**: 送信先は別ドメインだが、ポリシーで委託先として説明している

```text
念のため確認できる事項があります

⚠ フォームの送信先が現在のサイトとは異なるドメインです

運営会社情報:         確認できました
プライバシーポリシー: 見つかりました
```

→ 確かめること: ポリシーに書かれている委託先と、実際の送信先が同じサービスか。

**無料健康診断の申し込み**: 既往歴まで求めるが、ポリシーは Cookie の説明だけで、運営者も「事務局」としか書かれていない

```text
個人情報を入力する前に追加確認をおすすめします

⚠ サービスの運営主体を明確に確認できませんでした
⚠ 個人情報の利用目的を十分確認できませんでした
⚠ 収集する個人情報の説明を確認できませんでした
⚠ プライバシーポリシーがこのフォームで求められる情報に触れているか確認できませんでした
ℹ 第三者提供についての説明を確認できませんでした
ℹ 個人情報に関する問い合わせ窓口を確認できませんでした
```

→ 確かめること: 運営している会社・団体の名前と連絡先。既往歴のような健康情報を何に使い、誰に渡すのかの説明。
どちらも見つからなければ、入力しない方がよい場面です。

**解析タグが多い会員登録**: ポリシー・運営者は揃っている。外部スクリプトの多さは情報として示すだけ

```text
特に注意を促す兆候は確認できませんでした

ℹ 12種類の外部サービスのスクリプトがこのページで動作しています
```

このほか、HTTP のページでパスワードやカード番号を求める場合は「個人情報を入力する前に追加確認をおすすめします / ⚠ このページはHTTPSで保護されていません」、
評価サービスに接続できない場合は「現在評価できません」と表示し、問題なしとは扱いません。

## 構成

```text
extension/   ブラウザ拡張（TypeScript, Manifest V3, Firefox / Chrome 共通ソース）
relay/       Privacy Relay（Go）。Jev の credential を持つ唯一のコンポーネント
fixtures/    評価用ページ（DESIGN.md §34 の A〜H と adversarial）
docs/        privacy model / threat model / scoring
```

## 必要なもの

- Node.js 20 以上
- Go 1.25 以上
- Firefox 140 以上 / Chrome 120 以上

## ビルド

```sh
cd extension
npm install
npm run build          # dist/firefox と dist/chrome を生成
```

Relay の URL はビルド時に埋め込まれます（既定: `http://127.0.0.1:8787`）。設定画面からも変更できます。

```sh
node scripts/build.mjs --relay-url=https://relay.example.com
```

## Relay の起動

本物の Jev を使う場合は、環境変数 `JEV_API_KEY` に credential を設定して起動します。

```sh
cd relay
go run ./cmd/relay
```

Jev の API キーが無い場合は、キーワードベースの mock で動作を確認できます。

```sh
go run ./cmd/jevmock &                            # 127.0.0.1:8788
go run ./cmd/relay -jev-endpoint http://127.0.0.1:8788/v1/systemone
```

| フラグ / 環境変数 | 説明 |
|---|---|
| `-addr` | 待ち受けアドレス（既定 `127.0.0.1:8787`） |
| `-jev-endpoint` / `-jev-model` | Jev のエンドポイント / モデル（既定 `jev-latest`） |
| `-rate` | クライアントあたりの 1 分間のリクエスト上限（既定 30、0 で無効） |
| `-trust-proxy` | 信頼できるリバースプロキシの背後でのみ指定（`X-Forwarded-For` を使う） |
| `JEV_API_KEY` | Jev の credential |
| `RELAY_BEARER` | 設定すると `Authorization: Bearer <値>` を必須にする（拡張の設定画面の「Relay トークン」） |

## ブラウザへの読み込み

### Firefox

```sh
cd extension
npm run dev:firefox    # web-ext で一時的に読み込んだ Firefox を起動
```

または `about:debugging#/runtime/this-firefox` →「一時的なアドオンを読み込む」→ `extension/dist/firefox/manifest.json`。

### Chrome

`chrome://extensions` → デベロッパーモード →「パッケージ化されていない拡張機能を読み込む」→ `extension/dist/chrome`。

### 初回設定

インストール直後に設定画面が開きます。どのサイトにもアクセスしない状態で始まるので、次のどちらかで有効にします。

- 設定画面の「すべてのサイトで有効化」
- 評価したいページでツールバーのアイコン →「このサイトで有効化」

## 既知の制約（MVP）

- iframe 内のフォームは評価しません（top frame のみ）。
- 通信の観測は Resource Timing API と `script` / `iframe` 要素に基づく簡易集計です（`webRequest` は未使用）。
- Jev は日本語の精度が英語より低いと公式に記載されています。重みと閾値は実データで調整が必要です。
